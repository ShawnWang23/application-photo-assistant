# Web Privacy Policy Template

此文件是部署者上线前必须补全的模板，不能直接当作已经生效的法律文本。

Web 版与桌面版不同：照片和要求截图会上传到部署者控制的服务器内存中处理。部署者必须明确填写：

- 服务运营者和联系渠道。
- 图片是否写入磁盘、备份、对象存储或访问日志。
- 图片与文字的最长保留时间和删除机制。
- 日志中是否包含文件名、IP 地址和 Trace ID。
- 使用的第三方模型厂商、发送字段和适用地区。
- 用户访问、更正、导出和删除数据的方法。
- 服务器地区、加密措施、并发限制和事件响应流程。

上线要求：

1. 设置 `PHOTO_ASSISTANT_DEPLOYMENT=web`，禁用自定义 API Base URL。
2. 在上传前展示明确同意提示，不能继续宣传“照片不离开用户电脑”。
3. 配置 HTTPS、访问控制、请求体大小限制、速率限制和自动清理策略。
4. 不在环境变量、页面源码、日志或错误消息中暴露 API Key。
5. 完成适用于实际运营地区的隐私与合规审查。
